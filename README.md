# Organizador de Archivos

Codigo en Python para organizar automáticamente una carpeta separando archivos por tipo.

## Qué hace
- Mueve documentos a `Documentos`
- Mueve imágenes a `Imagenes`
- Mueve programas a `Programas`
- Crea las carpetas automáticamente si no existen

## Cómo usarlo

1. Tener Python instalado
2. Descargar el archivo `.py`
3. Ejecutar:

```bash
python organizador.py
